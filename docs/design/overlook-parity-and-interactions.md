# 星序工作台设计修订：Overlook 功能基线

## 范围
本轮只改设计与交互原型，不修改业务实现、不启动 Luna、不改 Overlook。不把演示状态当真实连接验收。旧版工作台将连接标签放在会话叶节点并混合项目归属的设计作废。

## 归属模型与显示层级（强约束，以用户截图修订为准）
- 数据归属仍按连接、机器/profile、稳定项目目录/原生 ID 隔离；但显示只有“项目 → 会话”两级，不将数据归属直接画成三层树。
- 所有来源的项目在同一个列表中混排，不设连接分区/连接父节点；避免项目多的连接把其他来源挤到列表底部。
- 项目行：展开箭头、图标、项目名、可选置顶、可选远程连接短标识、独立数量。远程标识在项目名右侧、数量左侧；本机不显示“本机/Local/default”等来源标识。
- 同名远程项目依靠项目行 WSL/Debian 等连接短标识区分；完整连接身份和 profile 放 tooltip/详情，不再增加目录层级。必要时区分本机多个 profile，也用详情/消歧名称，不重复挂本机标签。
- 会话叶节点只展示标题、时间、运行状态、未读/置顶，不挂连接名。每个项目默认仅展示少量会话及“展开其余”入口，控制单个项目占用高度。
- 排序跨连接执行（置顶优先，其余沿用用户排序/最近活动）；实时 token/状态刷新不打乱阅读位置。连接筛选仅为可选过滤器，不恢复连接分区。
- 不同连接下同名项目保持独立，不按名字合并；会话叶节点不挂连接名。
- 已断开的连接保留缓存项目，但明确标注离线/历史；不可冒充实时、禁止自动跨连接发送。
- 状态、未读、置顶分别编码。项目数量为该来源真实会话数量；未全量加载时显示“已加载 x / 总数未知”，不能假装齐全。

## 输入器结构
从上到下：
1. 运行条：分支与脏工作区、后台任务、Todo 完成数、子代理活跃数。非 Git 环境显示“非 Git 项目”；无权限或离线显示未知，不编造。
2. 可展开任务详情：默认摘要；活动发生时更新计数，不自动抢开面板。
3. 待发送队列与附件/引用预览：只在有内容时出现。
4. 多行输入框。
5. 附件、语音、模型/推理强度、上下文使用量、发送/排队、独立停止按钮。

运行时输入有内容→“加入队列”；停止始终是独立按钮，不能靠同一个图标隐式切换造成误停。队列必须显示所属会话，失败可重试/撤销。发送 ack 不代表 Agent 已完成。

## 状态与动效（设计规范，不等于已实现）
- 就绪：静态空心圆＋文字；思考：三点呼吸；工具运行：旋转环＋工具简称；等待审批：静态菱形＋“待审批”；排队：时钟＋数量；失败：错误图标＋重试；离线：断链图标；完成未读：静态实心未读标记。
- 动画只表达真实正在运行的状态，完成/失败/离线立刻停止；不可拿动画充当连接心跳。
- 旋转 1.2 秒线性；思考呼吸 1.4 秒；状态切换 160ms；抽屉 220ms。列表行高和顺序不随活动变化，不反复跳位。
- prefers-reduced-motion 下关闭旋转/呼吸/位移，保留图标与文字。后台不可见页面暂停装饰动画。
- 计数与图标固定宽度；hover 工具同样支持键盘焦点；状态用 aria-live=polite 节流播报，不逐 token 播报。
- 移动触控目标至少 44px；输入文字至少 16px，安全区与软键盘不遮挡操作。
- 语音状态：未授权→请求权限→录音计时/波形→停止→识别草稿或音频试听→用户确认。取消丢弃本次音频；拒绝授权不清空已有草稿。展示设备不支持、识别失败、断网回退。

## 本轮页面集合
桌面：工作台 V2、连接管理 V2、连接详情 V2、监控室。
移动：连接列表 V2、项目/会话浏览（远程标识只在项目上）、聊天运行态、任务详情、语音输入、SSH 添加连接。
预期 10 个页面；只有读取远端 screen IDs 和下载素材后才计入交付。

## 其他改进
- 错误只归属对应连接；“查看诊断”和“重试部署”职责不同，避免重复重试按钮。
- 添加 SSH 分步：基本信息→身份与主机密钥确认→自动部署/握手；不以默认勾选绕过信任确认。
- 手机不是桌面缩小版；任务和长日志进底部 sheet，分支和运行摘要仍在输入框上方可达。
- 不再将“全部任务”停止放在高频快捷区，改为二次确认的范围明确操作。
- 完整功能迁移尚需实现阶段逐项真实验收；设计图只说明功能位置与状态，不代表所有 Overlook 功能已完成移植。
