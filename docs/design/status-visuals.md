# 状态与提示的视觉规范

状态展示采用中性色、透明底文字和单色图标。状态徽标、能力标签、提示框及装饰性图标不使用彩底彩字胶囊、浅绿色背景或绿色勾选底座。

公共样式入口为 `frontend/src/theme.ts`：Badge 和 ThemeIcon 使用透明底；Alert 使用中性表面与细边框；light 变体按钮使用中性底色。已连接、已启用、运行正常等普通状态通过文字与图形表达。错误和警告保留明确文案及少量红色、琥珀色图标，提示底色保持中性。

自绘组件使用 `--astr-text`、`--astr-muted`、`--astr-surface-muted`、`--astr-border` 等语义变量，不另写绿色状态配色。新增状态组件同时检查手机/桌面和深浅主题。

用户主动选择的项目颜色、代码语法高亮、图表数据系列和 Git 增删内容保持各自的数据语义；它们不作为被动状态徽标的配色来源。
