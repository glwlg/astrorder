# Codex 工具钩子触发运行中消息更新

2026-10-15。

## 已确认的代码缺口

Go 小内核将 Codex 的 `UserPromptSubmit`、`PreToolUse`、`PostToolUse` 等钩子转为 `native.activity`；`Stop` 单独转为 `turn/completed`。App 原来仅将活动转换为会话时间更新，前端未消费运行中钩子作为原生历史变化通知。前端的 `native.observation` 分支不在当前 Go 发送链路中。

这说明安装钩子不足以保证运行中消息刷新；本次复现证明该缺口，未读取截图对应生产聊天，未证明其为全部停流问题的唯一原因。

## 修复

- App 将钩子活动投影为精确 agent/session 的 `transcript.invalidate`，消息正文仍从原生接口只读获取。
- 通知独立于 `updated_at` 比较：其他原生事件已推进会话时间时，钩子仍能通知页面。
- 前端按会话合并 250ms 内通知，保留进行中的历史读取；读取期间的新通知安排后续读取，卸载时清理定时器。
- 小内核未修改，现有工具钩子 5 秒节流仍在，不能把本修复描述成逐 token 镜像。

- 前端新测试修复前失败，修复后通过：合并事件、读取期间后续刷新、卸载清理。
- Go projection/application/sessions 214 项通过，相关 vet 通过。
