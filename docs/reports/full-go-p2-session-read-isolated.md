Bad native list rows, missing item lists, oversized business responses and invalid pagination fail explicitly. The business limit is exactly 16,000,000 bytes, distinct from the 33,554,432-byte gRPC wire limit.

Native history fixes:

- Codex owned history uses `thread/items/list` with native limit and descending sort, reverses the returned page to chronological order, retains the full native page, and validates a thread/Agent-scoped `codex:` continuation. Unsupported older native versions fail instead of fabricating a thread/read page.

Missing, foreign or ambiguous anchors fail; appended new messages do not shift an offset. Upstream gateway still sends the full history frame, so its memory/scanner limit remains an explicit gap.
