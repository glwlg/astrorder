# 工具过程按 100 项分组

本轮前端改动：连续工具／思考过程最多 100 项一组，组间显示分隔线，各组独立折叠。普通正文、用户消息和上下文压缩标记继续作为自然边界。手机沿用默认收起；桌面只默认展开当前运行的最后一组，前面的组自动收起。展开组时一次挂载该组全部项目，单项输出仍按需展开。

历史依旧从原生 API 读取，不新增 App 侧正文持久化。首次请求仍为 50 条；如果最早可见记录落在工具过程中，继续沿原生游标补齐该组至 100 项或自然边界，然后一次性发布到界面。后续请求为 100 条；遇到被原生分页切开的组同样补齐。保留每个加载批次的首项边界，加载更早记录不会将已显示的组重新合并；完整工具组出现后停止为寻找用户消息而自动追读整个长轮次。游标循环和中途读取错误会报错，不返回成功的半组。
